# 学历序列就业压力测算

▶ **在线使用：[zlfxjtu-dot.github.io/edu-pressure](https://zlfxjtu-dot.github.io/edu-pressure/)** —— 打开即用，手机上也能开

把一条「学历序列」（二本 → 双非 → 211本 → 双非硕 → 985本 → 211硕 → 985硕 → 双九硕）摆成一根位次轴，看某个岗位的招聘区间里，**每一层学历同时受到多大的挤压和替代**。

也可以下载后直接打开 [`index.html`](index.html)——不用构建、不用装依赖、不用起服务。

> ⚠️ **仓库里的数字是示意数据**，只为演示模型怎么算，不是任何真实统计。换成你自己的口径再用。

---

## 模型

序列上每一层学历，同时被两个方向的力夹着：

| 指标 | 含义 | 来源 |
| --- | --- | --- |
| **挤压阻力** | 上方往下挤 | 位次**更高**的学历人数 |
| **替代压力** | 下方往上顶 | 位次**更低**的学历人数 |

岗位分两类，区别只在对称性：

- **普通岗**——按位次分上下。**同级或更高都算挤压**，更低算替代。同层（并列）为什么算压力：这些人学历跟你等价，投的是同一批岗，是**直接竞争对手**，不是「既不算挤也不算替」。
- **考试岗**——只看分数和门槛，过了门槛学历高低就不起作用了。所有人面对的是**同一个池子**，所以挤压 = 替代 = 区间内**总人数**，区间内每层取值相同 —— 画出来是一条**水平线**，图上只画**一根**线。

> **考试岗为什么是水平线。** 它描述的是「池子规模」，与你是哪一层无关：过了分数线的人全在一个池子里竞争，学历高低不再区分谁强谁弱。所以它**包含本层**——你自己也在池子里。
> 取值 = 区间内总人数（含本层）＋边界渗透进来的区间外人＋基准竞争。

## 两条修正：为什么曲线不归零

照上面的定义硬算，序列**最底层**（下方确实没人）的替代压力必然是 0，**最顶层**（上方确实没人）的挤压也必然是 0。但「一点压力都没有」在现实中不成立——总有人跨区间乱投。所以加了两项，都能在页面上调：

- **边界渗透 `k`（默认 0.15）**——岗位区间不是硬墙。区间外**紧邻**的一档按 `k` 计入，再往外按 `k` 的幂衰减。岗位写「985本 ~ 双九硕」，双非硕的人照样会投，只是量级小得多。
- **基准竞争 `base`（默认 500）**——每层再垫一个固定的底。序列两端只能靠它兜底。

## 纵轴为什么默认对数

数据跨了 200 倍（`500` ~ `10.6万`）。线性轴上最小的那截只占全高 0.5%，曲线会贴死在底边**看都看不出来**。对数轴把下界压到最小值以下一整档（`200`），最低点才浮得起来。

代价是**纵轴间距读的是「倍数」不是「人数差」**——`500→1000` 和 `5万→10万` 画出来一样高。切成线性可以读绝对差值，代价是两端重新挤在一起。

顺带一提，线性轴下想让 `500` 那个点离底边 41px，轴的起点得落在 **−1.6 万**（13% 的图高用来画负人数）。所以这是两种刻度之间的取舍，不是没调好。

## 用法

- 左边**拖动**换位次，拖进同一行 = 并列；`↑` `↓` 调整整行顺序；每格填人数。
- 左栏标题里那个**口径标签**默认是「学历」，可以改。**改成「专业」，整套就按专业看人数**——标题、提示、人数框的说明都跟着走。工具本身不关心这一列装的是什么，填进去的只是「有人群 + 人数 + 位次」。
- 右边填岗位：一个学历区间 + 类型。
- **颜色 = 岗位，实线 = 挤压，虚线 = 替代**。同一岗位的两根线永远同色。
- 顶部两个输入框调**边界渗透**和**基准竞争**，`纵轴` 下拉切对数 / 线性。
- 左栏底部的**人数金字塔**按位次自下而上画各层人数，并把每个岗位的学历区间铺成一条**淡色带**——带的上、下两端各一条实线，就是该岗位区间的**上/下线**，落在哪两层之间一眼能看出来。两个岗位的带会重叠，重叠区正是被两个区间同时覆盖的学历。

> 金字塔**不保证单调收窄**——默认数据在硕士段就有个凸起（本科毕业去读研，人堆在那一档）。真实人口金字塔也有凸起，这不是画错了。

`src/pressure.js` 是唯一真相：页面里的默认序列和默认岗位都从它读取，不在 HTML 里再抄一份。

```bash
node --test test/pressure.test.js     # 17 条，全绿
node tools/check-page.js              # 语法 + 真跑 + 渲染计数
```

注意 `node --test test/` 这种**目录写法**在 Node v24.15.0 上会报 `MODULE_NOT_FOUND`，得写全文件路径。

## 实现上值得一提的两点

**曲线用单调三次插值（Fritsch–Carlson），不是 Catmull-Rom。** 数据里到处是「上升后走平」（比如顶端两层压力都触底），Catmull-Rom 在这种拐角会过冲，把曲线甩到 0 以下画出负值。单调版保证段内不越界，同时仍然精确穿过每个数据点。

**同层并列用下划线标出来。** 同一 tier 的多个学历在 x 轴上连着画一条短横线，把「位次相同」这个概念画出来。它们的挤压取值**完全相同**（都把自己和对方算进去），所以那一段曲线是平的。
