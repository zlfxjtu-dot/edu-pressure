# 学历序列就业压力测算

把一条「学历序列」（二本 → 双非 → 211本 → 双非硕 → 985本 → 211硕 → 985硕 → 双九硕）摆成一根位次轴，看某个岗位的招聘区间里，**每一层学历同时受到多大的挤压和替代**。

打开 [`index.html`](index.html) 就能用——不用构建、不用装依赖、不用起服务。

> ⚠️ **仓库里的数字是示意数据**，只为演示模型怎么算，不是任何真实统计。换成你自己的口径再用。

---

## 模型

序列上每一层学历，同时被两个方向的力夹着：

| 指标 | 含义 | 来源 |
| --- | --- | --- |
| **挤压阻力** | 上方往下挤 | 位次**更高**的学历人数 |
| **替代压力** | 下方往上顶 | 位次**更低**的学历人数 |

岗位分两类，区别只在对称性：

- **普通岗**——上下不对称。更高的压下来算挤压，更低的顶上来算替代；**同一层（并列）互不算**。这对应「大家投的是同一个岗，学历越高越占优」。
- **考试岗**——只看分数和门槛，过了门槛学历高低就不起作用了。所以挤压 = 替代 = 区间内其他所有人，两根曲线重合。

## 两条修正：为什么曲线不归零

照上面的定义硬算，序列**最底层**（下方确实没人）的替代压力必然是 0，**最顶层**（上方确实没人）的挤压也必然是 0。但「一点压力都没有」在现实中不成立——总有人跨区间乱投。所以加了两项，都能在页面上调：

- **边界渗透 `k`（默认 0.15）**——岗位区间不是硬墙。区间外**紧邻**的一档按 `k` 计入，再往外按 `k` 的幂衰减。岗位写「985本 ~ 双九硕」，双非硕的人照样会投，只是量级小得多。
- **基准竞争 `base`（默认 500）**——每层再垫一个固定的底。序列两端只能靠它兜底。

## 纵轴为什么默认对数

数据跨了 200 倍（`500` ~ `10.6万`）。线性轴上最小的那截只占全高 0.5%，曲线会贴死在底边**看都看不出来**。对数轴把下界压到最小值以下一整档（`200`），最低点才浮得起来。

代价是**纵轴间距读的是「倍数」不是「人数差」**——`500→1000` 和 `5万→10万` 画出来一样高。切成线性可以读绝对差值，代价是两端重新挤在一起。

顺带一提，线性轴下想让 `500` 那个点离底边 41px，轴的起点得落在 **−1.6 万**（13% 的图高用来画负人数）。所以这是两种刻度之间的取舍，不是没调好。

## 用法

- 左边**拖动**学历换位次，拖进同一行 = 并列；`↑` `↓` 调整整行顺序；每层填人数。
- 右边填岗位：一个学历区间 + 类型。
- **颜色 = 岗位，实线 = 挤压，虚线 = 替代**。同一岗位的两根线永远同色。
- 顶部两个输入框调**边界渗透**和**基准竞争**，`纵轴` 下拉切对数 / 线性。

## 实现上值得一提的两点

**曲线用单调三次插值（Fritsch–Carlson），不是 Catmull-Rom。** 数据里到处是「上升后走平」（比如顶端两层压力都触底），Catmull-Rom 在这种拐角会过冲，把曲线甩到 0 以下画出负值。单调版保证段内不越界，同时仍然精确穿过每个数据点。

**同层并列用下划线标出来。** 同一 tier 的多个学历在 x 轴上连着画一条短横线，把「位次相同」这个概念画出来——它们之间互不算挤压也不算替代。
